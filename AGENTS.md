# white-collar-bench agent instructions

## Synthetic data only

This benchmark is inspired by the structure of a real, private knowledge-work repository. That repository contains confidential work details.

- Every project, person, organization, email, document, meeting, date and other detail in this repository must be synthetic.
- Borrow patterns only: record types, workflows, failure modes and task shapes. Never copy, paraphrase or lightly disguise real names, projects, customers, products, events or quotations.
- Do not read private source repositories while authoring benchmark content unless the user explicitly asks for a pattern-level review, and never transcribe their contents.
- If generated content resembles a real person or organization, replace it.
